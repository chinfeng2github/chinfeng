## 🧑‍💻 关于我

> 15 年全栈开发经验，近 10 年专注于微服务架构设计、分布式系统治理与研发效能提升。

坐标 **成都**，是一名经验丰富的全栈工程师。在过去 14 年多的时间里，作为技术核心主导了核心系统从单体架构到 Spring Cloud 微服务体系的全链路演进。

热爱端到端地构建产品——从分布式后端架构设计、CI/CD 流水线搭建，到跨平台移动应用开发和云基础设施管理。

- 📱 **移动端与前端** — React Native、Flutter、Vue3、Tauri2 — 从设计到上架全生命周期
- ⚙️ **DevOps 与基础设施** — Docker、Ansible、Terraform、CI/CD 流水线、ELK 栈、多云资源管理
- 🤖 **AI 集成** — ComfyUI 工作流、Dify AI 流水线、LLM 功能集成
- 🛠️ **跨平台开发** — 独立开发并上架 3 款 iOS/Android App
